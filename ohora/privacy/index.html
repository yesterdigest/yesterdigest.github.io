개인정보처리방침 — 오호라! (ohora-shorts)

시행일 2026년 10월 4일

1. 이 방침이 다루는 것

이 방침은 오호라! 운영자가 쓰는 「ohora-shorts」 앱(Google Cloud 프로젝트 ohora-shorts)이 Google·YouTube 사용자 데이터를 어떻게 다루는지 설명합니다. 이 앱은 운영자 본인의 YouTube 채널(@ohorashorts)에 영상을 올리기 위한 내부용 도구이며, 일반 사용자에게 제공되지 않습니다.

2. 이 앱은 YouTube API 서비스를 사용합니다

이 앱은 YouTube API Services를 사용합니다. 이 앱을 쓰는 것은 YouTube 서비스 약관에 동의하는 것입니다. Google의 데이터 처리는 Google 개인정보처리방침을 따릅니다.

3. 접근하는 데이터와 쓰는 목적

  • 운영자 본인 채널에 영상 업로드, 제목·설명·태그·공개 예약 설정, 업로드한 영상의 상태 확인
  • 이 목적 밖으로 데이터를 쓰지 않으며, 다른 사람의 계정·채널·개인정보를 수집하지 않습니다.

4. 저장과 보관

인증 토큰은 운영자 컴퓨터의 비공개 설정 파일에만 저장되며, 코드 저장소·서버·제3자에게 올리지 않습니다. 앱이 받은 YouTube 데이터는 업로드 결과 확인용 기록(영상 ID·게시 시각)만 운영자 컴퓨터에 남깁니다.

5. 공유

Google 사용자 데이터를 판매하거나 제3자와 공유하지 않습니다. Google API에서 받은 정보의 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

6. 접근 권한 철회와 삭제

언제든지 Google 계정 보안 설정에서 이 앱의 접근 권한을 철회할 수 있습니다. 철회하거나 삭제를 요청하시면 운영자 컴퓨터의 토큰과 기록을 지체 없이 지웁니다.
